# 例子：长跑注册 / 收码

对照 [launch](../dimensions/launch.md) 与 [resilience](../dimensions/resilience.md)。不绑定具体站点或供应方。

| 当时的坑 | 用了哪一条 |
|----------|------------|
| 几份脏资源空转到天亮 | resilience §2：禁止熔断新获取；有限次失败后退役 + 申诉 |
| 便宜类型一失败就只打最贵的一类 | resilience §4：按件数交错，类型只软暂停 |
| 把「请 N 分钟后再试」当成「对方不认这类资源」 | resilience §1 读原文；§3 不再连点提交 |
| 资源已被拒绝仍对同一域名重试 | resilience §2：立刻退役 + 拉黑该资源 + 换类型采购 |
| 已发码却短窗口放弃并重提 | resilience §5：留页加长等，同时打列表接口 |
| 别名/变体被当成新身份连发 | resilience §4：归一 key |
| 接口、运行时或内存把整场打死 | resilience §6 §7；launch 阶段 5–6 |

写新例子时继续用这张表：左列是现场，右列是纬度编号。
